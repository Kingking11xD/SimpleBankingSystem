# Secure C++ Banking System

A console-based banking application built with C++ using Object-Oriented Programming. Features account creation, PIN security, and file-based data saving.

## Prerequisites
You must have a C++ compiler installed (like GCC, Clang, or MSVC).

## How to Run
1. Clone this repository to your local machine.
2. Open your terminal and navigate to the project folder.
3. Compile the code:
   `g++ src/main.cpp src/BankAccount.cpp src/BankManager.cpp -o bank`
4. Run the application:
   - **Windows:** `bank.exe`
   - **Mac/Linux:** `./bank`
